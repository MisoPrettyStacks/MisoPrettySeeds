# MisoPretty Seeds 🌱

Online shop for MisoPretty Seeds — small-batch flower seeds, packed with love in California.

**Live site:** https://misoprettystacks.github.io/MisoPrettySeeds/

## How ordering works

No carts, no checkout — customers DM [@igotglitteronme](https://x.com/igotglitteronme) on X with the varieties they want, pay via Cash App / Venmo / Zelle / PayPal, and the seeds ship out.

## Products

$4.99 each: Common Sunflower, Cosmos, Mammoth Sunflower, Nasturtium, Poppy, Lavender (+ Flower placeholders for upcoming varieties).
